# UX Interface Evaluation – IDE2IL

## 🎯 Ziel
Wendet die mentalen und physischen Usability-Frameworks aus den ersten beiden IDE2IL Sessions an, um reale Interfaces zu evaluieren.  
Ziel ist es, das eigene Auge für UX-Muster zu trainieren und Beobachtungen mithilfe der Theorie zu argumentieren.

---
# 👥 Setup

- Teams aus **2 Personen**

---

# 🔍 Schritt 1: Suche

Sucht gemeinsam nach **realen Interfaces aus eurem Alltag**.  
Die Plattform ist egal, z. B.:

- Desktop
- Mobile
- Konsole
- Smartwatch
- Fahrkartenautomat
- Web-Anwendungen
- Haushaltsgeräte

Sammelt insgesamt:

- **5 Interfaces mit guter Usability**
- **5 Interfaces mit schlechter Usability**

💡 **Tipp:**  
Wählt nicht nur Interfaces mit hübscher UI oder kleinen Fehlern.  
Sucht Systeme mit **echten Usability-Problemen und interessanten Designentscheidungen**, da einige Beispiele später detaillierter analysiert werden.

---
# 🧠 Schritt 2: Analyse

Erstellt für **jedes Interface ein kurzes Profil** mit:

- Screenshots oder Fotos
- Kommentaren und Bewertung

## 1. Kontext

**Welt (IDE2IL1)**  
- In welcher Interface-Welt bewegen wir uns?  
  Beispiele: Desktop, Mobile App, Embedded System, Kiosk Interface, etc.

**Form Faktor (IDE2IL2)**  
- Welches physische Setup liegt vor?  
  Beispiele:
  - Smartphone
  - Laptop / Desktop
  - Touchscreen Terminal
  - Smartwatch
  - Game Controller

---
## 2. Usability-Bewertung

Bewertet das Interface anhand der besprochenen **Usability-Faktoren**, z. B.:

- **Effizienz** – Wie schnell lassen sich Aufgaben erledigen?
- **Learnability** – Wie leicht ist das System zu erlernen?
- **Memorability** – Kann man es nach längerer Zeit wieder intuitiv nutzen?
- **Fehlertoleranz** – Wie gut geht das Interface mit Fehlern um?
- **Feedback** – Gibt das System verständliche Rückmeldungen?
- **Konsistenz** – Verhalten sich Elemente vorhersehbar?

Optional könnt ihr zusätzlich bewerten:

- **Visuelle Hierarchie**
- **Navigation**
- **Mental Model Fit**
- **Zugänglichkeit**

---
# 📦 Schritt 3: Zusammenfassung

Bereitet eure Ergebnisse **visuell** auf.

Mögliche Formate:

- **Miro Board**
- **FigJam**
- **Slides / Präsentation**
- **Figma Board**

Die Zusammenfassung sollte enthalten:

- Screenshots / Fotos der Interfaces
- kurze Analyse pro Interface
- klare Kennzeichnung:
  - 👍 Gute Usability
  - 👎 Schlechte Usability
- kurze Begründung anhand der Theorie

---
# ✅ Erwartetes Ergebnis

Am Ende habt ihr:

- **10 analysierte Interfaces**
- eine **strukturierte UX-Bewertung**
- eine **visuelle Präsentation eurer Findings**
