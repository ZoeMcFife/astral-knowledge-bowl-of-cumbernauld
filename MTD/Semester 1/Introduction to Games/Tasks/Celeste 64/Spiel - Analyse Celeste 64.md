Motivation

Was ist speziell an diesem Spiel?

Das Spiel wurde als 6tes Jubiläum des Spiels Celeste in einer Woche im Gamejam style erstellt. Das besondere auch dabei ist, dass es als Teil-Fortsetzung zum Spiel Celeste dient. Dies sorgt natürlich für die Fans, die das Spiel Celeste feiern über eine große Freude.

Gibt es ähnliche Spiele?

Der Vorgänger von Celeste 64 Framents of the Mountain ist Celeste. Celeste 64 wurde sozusagen von Celeste inspiriert. Das Spielprinzip erinnert auch an Mario 64 auf dem Nintendo 64.
